# Awesome Web Geospatial - Summary

## What This Repository Contains

A curated list of **web-specific** geospatial tools, libraries, and utilities. **Objective, factual, and descriptive** - no benchmarks, no subjective claims.

## Approach

**It-is-what-it-is**: Each entry describes:
- ✅ What the tool does
- ✅ Technical characteristics (rendering approach, dependencies, requirements)
- ✅ Known limitations and constraints
- ✅ License type and ecosystem context

**What we don't include:**
- ❌ Bundle sizes (they change, depend on build configuration)
- ❌ Download counts (they fluctuate, don't indicate quality)
- ❌ Performance benchmarks (context-dependent)
- ❌ Star counts (don't indicate usefulness)
- ❌ Subjective language ("best", "amazing", "powerful")
- ❌ Recommendations (users decide based on their needs)

## What Makes This List Different

### Removed Unrelated Content
- ❌ Desktop GIS tools (QGIS, QGIS Cloud, QGIS Tutorials)
- ❌ Python geospatial tools (GeoPython Tutorials)
- ❌ Proprietary cloud platforms (Google Earth Engine)
- ❌ General-purpose visualization (Plotly.js, 3d-force-graph, jVectorMap)
- ❌ Abstract geometry libraries (geometric.js, flatten-js)
- ❌ Data collection platforms (OpenStreetCam, KartaView)
- ❌ Complete end-user applications (OpenSphere)
- ❌ Defunct services (Stamen Design - absorbed by Stadia Maps)

### Added Genuinely Relevant Web Tools
- ✅ **Map UI Components** - locate controls, minimaps, fullscreen, compass, layer switchers
- ✅ **Measurement Tools** - distance/area measurement, elevation profiles
- ✅ **Map Animation** - time dimension, wind velocity visualization, style transitions
- ✅ **Map Export** - screenshot, image export, video export
- ✅ **Offline Maps** - PouchDB caching, PMTiles offline support
- ✅ **Routing Clients** - Leaflet Routing Machine, MapLibre GL Directions
- ✅ **Geocoding Controls** - Leaflet Control Geocoder, MapLibre Geocoder
- ✅ **WMS/OGC Clients** - Full-featured WMS plugins
- ✅ **3D Integration** - Threebox for custom 3D models
- ✅ **Spatial Indexing** - kdbush, geokdbush, tinyqueue
- ✅ **Framework Wrappers** - Official MapLibre Angular bindings, advanced React components
- ✅ **Style Tools** - MapLibre style specification utilities
